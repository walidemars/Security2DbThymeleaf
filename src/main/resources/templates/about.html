Описание приложения

Данное веб-приложение разработано для управления информацией о фильмах, актерах и кассовых сборах.

Основные возможности:
  • Управление списком фильмов (добавление, редактирование, удаление)
  • Управление списком актеров (добавление, редактирование, удаление)
  • Управление информацией о кассовых сборах
  • Расчет общих кассовых сборов по фильмам и годам
  • Система ролей пользователей (READ_ONLY, USER, ADMIN)
  • Управление ролями пользователей (для администраторов)
Технологии:
  • Java Spring Boot
  • Spring Security
  • Spring Data JPA
  • H2 Database
  • Thymeleaf
  • Bootstrap
  • Spring Boot Actuator
Роли пользователей:
  • READ_ONLY - только просмотр данных
  • USER - полный доступ к созданию, редактированию и удалению общих записей
  • ADMIN - полный доступ ко всем данным и управление пользователями
